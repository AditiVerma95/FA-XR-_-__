# MR Prototype – FA-XR-___

## Candidate Information
- Name: Aditi Verma
- Candidate ID: FA-XR-___

## Unity Version
- Unity 6000.3.10f1

## Device Tested
- Meta Quest 3s
- Tested using Air Link as well as Wired connection through Build and Run

## Packages / SDKs Used
- Meta XR All-in-One SDK
- XR Interaction Toolkit
- TextMeshPro

## Features Implemented
- Mixed Reality table/platform spawning
- Ball interaction using hand tracking
- Pick up and throw functionality
- Ball reset functionality

## Controls
- Middle and Ring finger touch gesture to spawn table
- Pinch gesture to interact with objects
- Reset button respawns the ball

## What Works
- Hand tracking interaction
- Object grabbing
- Ball physics and throwing
- Reset system
- MR object placement

## Known Issues / Limitations
- Hand tracking may briefly delay on startup
- Tracking quality depends on room lighting

## Setup Instructions
1. Open the project in Unity
2. Ensure Meta XR plugins are enabled
3. Connect Meta Quest device
4. Build and Run on Android/Quest

## Notes
- Only Unity primitives were used for the environment and interactable objects.
- Project created for MR prototype screening task.
